# WinTrack 17.0 – Český překlad

První komunitní český překlad programu WinTrack 17.0.

Součástí projektu je automatický instalační program (Setup) pro snadnou instalaci českého překladu i přenosná verze pro ruční instalaci.

## ⬇️ Stažení českého překladu

**[Stáhnout nejnovější vydání – WinTrack 17.0 CZ v1.1](https://github.com/Zeyvix-dev/WinTrack-Czech-Translation/releases/tag/v1.1)**

Na stránce vydání otevřete část **Assets** a stáhněte soubor `WinTrack-17-CZ-Translation-v1.1-release.zip`.

Balíček podle popisu vydání obsahuje instalační verzi, přenosnou EXE verzi a české zdrojové jazykové soubory. Před instalací doporučujeme zálohovat původní soubory WinTracku.

WinTrack 17.0 čeština  
WinTrack čeština  
WinTrack český překlad  
WinTrack CZ  
WinTrack 17 CZ Translation

## Instalace

1. Stáhněte balíček z [nejnovějšího vydání v1.1](https://github.com/Zeyvix-dev/WinTrack-Czech-Translation/releases/tag/v1.1).
2. Ukončete WinTrack, pokud je spuštěný.
3. Rozbalte ZIP a postupujte podle přiložených instalačních pokynů.
4. Pokud instalujete ručně, vyberte složku, kde je WinTrack nainstalován. Příklad: `C:\\Program Files (x86)\\WinTrack\\`
5. Před nahrazením souborů si vytvořte jejich zálohu.
6. Spusťte WinTrack a ověřte, že se překlad načetl.
